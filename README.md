# ETF 투자 유형 테스트

회사 제안·시연용으로 제작한 GitHub Pages 정적 웹사이트입니다.

## 구성

- `index.html` — 화면 구조
- `style.css` — 아기자기한 반응형 디자인
- `script.js` — 12문항 진행, 점수 계산, 16개 결과 유형

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일 3개(`index.html`, `style.css`, `script.js`)를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch를 `main`, 폴더를 `/ (root)`로 선택하고 저장합니다.
6. 잠시 뒤 표시되는 GitHub Pages 주소로 접속합니다.

## 문구 수정

- 테스트명·첫 화면 문구: `index.html`
- 질문 및 결과 유형: `script.js`
- 색상·폰트·레이아웃: `style.css`

## 폰트

Google Fonts의 `Jua`, `Gowun Dodum`을 사용합니다. 인터넷 연결이 없을 때는 기본 한글 폰트로 표시됩니다.

## 주의

본 테스트는 콘텐츠용 성향 테스트이며 실제 투자 적합성 진단이나 금융상품 추천을 목적으로 하지 않습니다.
